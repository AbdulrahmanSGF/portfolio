# AbdulrahmanSGF Portfolio

A static, responsive cybersecurity portfolio prepared for GitHub Pages.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `portfolio`.
2. Upload every file and folder from this package to the repository root.
3. Commit the files to the `main` branch.
4. Open the repository's **Settings**.
5. Select **Pages** in the sidebar.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select the `main` branch and the `/ (root)` folder, then press **Save**.

GitHub will provide a URL similar to:

`https://AbdulrahmanSGF.github.io/portfolio/`

## Customize later

- Edit page content in `index.html`.
- Edit colors and layout in `styles.css`.
- Edit the typing and hexadecimal effects in `script.js`.
- Replace images inside `assets/`.

All website asset paths are relative, so the portfolio works in a project repository or a `username.github.io` repository.
